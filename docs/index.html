J.A.R.V.I.S

A voice assistant for your Mac, inspired by Iron Man's JARVIS. Say “Jarvis, wake up” and talk to it. It answers out loud, remembers things about you and takes on longer jobs while you carry on.

GET IT ON GITHUB WATCH THE DEMO

What it does

An assistant you talk to, not a chat window

Most voice assistants answer questions and run a fixed set of commands. JARVIS runs on Claude Code, so it can work with your files, your browser and your coding sessions, and keep you posted while a long job runs in the background.

Hands-free

Say the wake word and every sentence after it is a command, until you tell it to sleep. Say its name while it's talking to stop it.

“Jarvis, wake up.”

Quick replies, slow jobs in the background

A fast model answers right away and hands anything long to a stronger one. Progress shows on the HUD, and it speaks up when the job finishes, fails or needs you. You can keep talking to it meanwhile.

“What's the status?”

Uses your Mac

Your signed-in Chrome for Gmail, YouTube or LinkedIn, your files and shell, your Claude Code sessions, and other apps through Accessibility. It asks before taking over the mouse.

“Check my Gmail and tell me what needs a reply.”

Remembers you

People, preferences, projects and routines get saved as they come up. The MEMORY tab lists every fact, and you can delete any of them.

“My sister Priya's birthday is on the fourteenth.”

Speaks up when there's a reason

A morning briefing, spoken reminders, routines you set by voice, and the occasional check-in when something is worth mentioning.

“Every morning at eight, check the AI news.”

Honest about results

Background jobs come back as done, unverified or failed, and it won't call something done that it couldn't check. Text from emails and web pages is never treated as an instruction.

“I pressed send, but I couldn't confirm it went through.”

A voice with some character

A calm British butler with a dry sense of humour. When it looks something up, it tells you what it found in its own words and skips the list of links.

“Twenty past nine, sir.”

Your other computers

Several Macs, one JARVIS

Pair your computers with an 8-character code. No accounts, router settings or SSH. Then hand work to the other one, or switch the HUD to it and see everything it's doing.

Hand work over

Ask for something to be done on the other laptop, where you're already signed in. It runs there as a background job and the result comes back to you.

“Post this from the home Mac.”

A picker at the top of the HUD lists every computer that can be reached right now. Pick one to see its system info, sessions, jobs, chat, history and memory.

Talk to its agent

While another computer is in view, its agent's name wakes this Mac too. Its answer is spoken here, in its own voice.

“Friday, wake up.”

Private by design

The computers find each other peer to peer through Hyperswarm and connect directly, encrypted end to end. If a network blocks that, messages go through an ntfy relay, encrypted first so the relay can't read them.

From the terminal

Type instead of talking

When you're already at the keyboard, typing is quicker. The jarvis command talks to the same brain, memory and conversation as the voice, so you can start something by voice and finish it by typing. Replies are printed, not spoken.

# once: sh scripts/install-cli.sh
jarvis "what's on my calendar today"
jarvis                 # chat; /help lists commands
jarvis hud             # open the HUD
jarvis listen          # mic and wake word on
jarvis agents          # jarvis agent friday
jarvis devices         # jarvis device "Home Mac"
jarvis pair            # or: jarvis pair <code>
jarvis --on "Home Mac" "pull the repo"
  • If JARVIS isn't running, the command starts it in the background with no HUD and the microphone off.
  • It still asks before it sends, posts, deletes or pays, and you answer in the terminal. Ctrl-C stops an answer.
  • It goes through a private socket in ~/.jarvis that only your user can open. Nothing goes over the network.
  • JARVIS's own brain and workers can't run it, so nothing JARVIS reads can type commands to it as you.

How it works

From your voice to a finished job

Simple things like music, stop or the time never leave the Mac. Everything else goes to the brain, which answers itself or starts a background job.

01 · LISTENApple's on-device recogniser hears the wake word and your command, with echo cancellation so it ignores its own voice.
02 · THINKA fast model answers small questions in a couple of seconds. Anything longer goes to a background worker on a stronger model.
03 · WORKWorkers use Chrome, your files, your apps and your sessions. They check their results and send short status lines as they go.
04 · SPEAKKokoro reads the answer sentence by sentence as it arrives, so it starts talking before the whole reply is ready.
Privacy and safety

It has real access to your Mac, so it asks first

The Claude Code brain and its workers run without permission prompts, which is what lets them drive your browser. Spoken confirmation takes the place of those prompts.

  • It reads the task back and waits for a yes before anything that sends, posts, deletes, publishes, pays or changes account settings.
  • Text in emails, web pages and documents is treated as information. If an email asks it to do something, it tells you instead.
  • Your own Claude Code deny rules and hooks still apply, and it can't edit its own code, its config or your Claude settings.
  • It reads other apps through Accessibility and asks before it moves your mouse. You can switch that off.

Get started

Install

# macOS 14+, Node.js 20+, Xcode command line tools
git clone https://github.com/ashwinsingh2007/J.A.R.V.I.S.git jarvis
cd jarvis
./setup.sh      # packages, Swift helpers, voices
./build.sh      # makes JARVIS.app
open JARVIS.app
  • Setup asks for your name and lets you pick the brain, how it listens and the voice.
  • macOS asks for microphone and speech recognition access on first launch.
  • For the full agent, install Claude Code. For a free local setup, install Ollama.
  • Python 3.10+ is needed for the Kokoro voice; without it, the macOS voices still work.

Questions

FAQ

Is it free?

Yes. JARVIS is free and open source under the MIT licence. With the Claude Code brain it uses your existing Claude subscription; with the Anthropic API you pay Anthropic for what you use; Gemini has a free tier; with Ollama it costs nothing.

Does it work offline?

Partly. The wake word, speech recognition and the Kokoro voice run on your Mac. The brain needs Claude unless you use a local model through Ollama.

Does it always listen to me?

It listens for the wake word on the device. After "wake up" it treats what you say as commands until you say "sleep". "Standby" turns the microphone off, and "Disable" in the HUD releases it completely.

Can it send emails or messages on its own?

Only after you confirm. It reads the message back and waits for a yes before it sends, posts, deletes or pays for anything.

Does it run on Windows or Linux?

Not yet. It relies on macOS for speech recognition, Accessibility and the Keychain.

Can I change the wake word or the voice?

Yes. Each assistant has its own voice, wake words, brain and model in the HUD's Agents tab, and the speech recogniser is in Settings.

Can I use it without talking?

Yes. Type in the HUD's input bar, or use the jarvis command in the terminal, which can run JARVIS with no HUD and the microphone off.

Is this related to Marvel or Anthropic?

No. It's an independent project inspired by the films. "Claude" and "Claude Code" are trademarks of Anthropic.
